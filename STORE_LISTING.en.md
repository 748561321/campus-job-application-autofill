# Store Listing (English)

## Name
Campus Application Autofill

## Short description
Locally preview and fill Chinese and English campus application forms without automatic submission.

## Detailed description
Campus Application Autofill helps applicants reuse a locally saved profile across recruitment forms. It recognizes common personal, education, family, language, project, internship and work fields. Scanning begins only after the user clicks the scan button. Existing values are preserved by default, and every result should be reviewed before submission.

The extension does not upload resumes or web page contents, collect browsing history, or submit forms automatically. Diagnostic exports are redacted automatically, but users should inspect them before sharing.

This extension is not affiliated with or endorsed by any recruitment platform, bank, state-owned enterprise, or employer.
