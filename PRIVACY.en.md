# Privacy Policy

Campus Application Autofill is designed to work locally.

- Profile data is stored only in the browser's local extension storage.
- The extension does not upload resumes, profile data, page content, or browsing history.
- It reads an application page only after the user clicks **Scan current page**.
- It does not submit application forms.
- Diagnostic exports automatically redact common names, phone numbers, identity numbers, email addresses, and addresses. Users should still inspect exported files before sharing them.
- Exported profile backups contain private data and must be stored securely.

The extension does not use analytics, advertising identifiers, remote code, or data-sale services.
