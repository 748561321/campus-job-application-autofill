# Campus Application Autofill

A privacy-first Chrome/Edge extension for previewing and filling campus recruitment forms in Chinese and English.

## Highlights

- Works only after you click **Scan current page**.
- Keeps profile data in browser local storage.
- Supports common personal, education, family, language, work and internship fields in Chinese and English.
- Preserves fields that already contain a value by default, including component-based dropdowns.
- Never submits an application automatically.
- Exports redacted diagnostics for troubleshooting.

## Install locally

1. Download or build the release ZIP and extract it.
2. Open `chrome://extensions` or `edge://extensions`.
3. Enable Developer mode.
4. Choose **Load unpacked** and select the extracted folder.
5. Open **Manage local profile**, create or import a profile, and save it.
6. On an application form, click the extension and then **Scan current page**.
