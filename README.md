# 校招网申助手

[English](README.en.md)

一个本地优先、需要用户主动操作的中英文网申表单辅助扩展。它识别当前招聘页面中的字段，展示匹配结果，并在用户确认后填写高置信字段。它不会自动提交申请、处理验证码、代答测评或上传附件。

## 隐私设计

- 只有点击“扫描当前页面”后才临时访问当前标签页。
- 资料保存在浏览器扩展的本地存储中，不上传服务器。
- 默认不收集遥测、浏览历史和表单内容。
- 诊断文件导出前会遮盖已知姓名、电话、身份证号、邮箱和地址；分享前仍需人工检查。
- 默认保护页面已有内容，不自动覆盖，包括常见组件化下拉框。
- 界面可在中文和 English 之间切换，并记住语言选择。

## 本地安装

1. 下载或克隆本仓库。
2. 打开 `edge://extensions/` 或 `chrome://extensions/`。
3. 开启开发人员模式，选择“加载解压缩的扩展”。
4. 选择本项目目录。
5. 打开“管理本地资料”，通过格子填写资料并保存。
6. 打开招聘表单，点击扩展中的“扫描当前页面”，确认后再填写。

## 安全提醒

不要提交真实资料、导出的备份、诊断文件、简历、成绩单或证书。仓库已提供 `.gitignore`，但提交前仍应执行隐私扫描。

## 支持范围

支持普通输入框、文本域、原生下拉框、常见Vue/React受控输入，以及部分 Element Plus、Ant Design 和招聘系统自定义组件。网站更新后可能需要更新适配规则。
